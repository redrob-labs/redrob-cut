# Releasing Redrob Cut

- **Version:** `[workspace.package] version` in the root `Cargo.toml` is the single source. `cargo xtask version` prints it; `cargo xtask version set X.Y.Z[-pre]` changes it (`Cargo.toml` and `Cargo.lock`). `redrob-cut --version` and `redrob-cut-cli --version` print it. The packaging scripts (`packaging/env.sh`) read `FILMCRAFT_VERSION` (override), `FILMCRAFT_BUILD_SHA` (the macOS `Info.plist` records it) and `FILMCRAFT_BUILD_DATE` (AppStream release date); the workflow sets all three.
- **Cut a release:** cut `release/X.Y.Z` from `develop`, run `cargo xtask version set X.Y.Z` there, open a pull request to `main` and merge it with a merge commit. Tag the merge commit `vX.Y.Z` on `main`, push only the tag, then open the back-merge pull request `main` -> `develop`. The tag runs `.github/workflows/release.yml`, which fails if the tag is not the Cargo.toml version, and creates or updates the draft GitHub Release `Redrob Cut vX.Y.Z` with every artifact and `SHA256SUMS.txt` (notes generated from the merged pull requests; a `-rc.N` version is marked as a pre-release). Publish the draft after checking its assets and the job summaries (a `::warning::` there means a signing secret was missing and that artifact is unsigned).
- **Re-runs:** pushing the same tag again (delete and re-create it) rebuilds the draft and replaces its assets. Once the release is published the workflow refuses that version: bump it and tag again.
- **Dry run:** *Actions › Release › Run workflow* (optionally with `version: X.Y.Z-rc.N`, applied with `cargo xtask version set` in each job) builds every job and drafts nothing.
- **Artifacts** (`redrob-cut-<version>-<os>-<arch>.<ext>`): macOS universal `.dmg` (Developer ID signed, notarized, stapled; window from `packaging/macos/dmg/`) and `redrob-cut-cli-<version>-macos-universal.zip`; Windows x64, x86 and arm64 `.msi` and `-portable.zip` (arm64 cross-compiled; `.github/workflows/windows-arm64.yml` installs it on ARM64 hardware; signed with the organization's `WIN_CSC_LINK` certificate); Linux x86_64 and aarch64 `.AppImage` (+ `.AppImage.zsync` for AppImageUpdate delta updates), `.deb`, `.rpm`, `.tar.gz` (with `install.sh`), built on `ubuntu-22.04` so they need glibc 2.35+; `redrob-launcher.json`; `SHA256SUMS.txt`. Windows, macOS and Linux only; the web build in `cargo xtask web` is not a release artifact.
- **Fonts:** every build job checks out craft-fonts at a pinned commit (the `ref:` marked `bump deliberately`) and builds with `CRAFT_FONTS_DIR` and `CRAFT_FONTS_REQUIRED=1`, so releases embed its Japanese fonts and fail rather than ship without them. Bump the pin in every job at once.
- **Secrets:** redrob-labs organization secrets, used only by the jobs in the `release` environment (macOS, Windows, the draft). macOS: `APPLE_CODESIGN_CERT_P12_BASE64`, `APPLE_CODESIGN_CERT_PASSWORD` (Developer ID certificate, imported by `packaging/macos/import-cert.sh`) and `APPLE_NOTARY_API_KEY_P8_BASE64`, `APPLE_NOTARY_API_KEY_ID`, `APPLE_NOTARY_API_ISSUER_ID` (App Store Connect API key for `notarytool`). Windows: `packaging/windows/sign.ps1` reads `WINDOWS_CERTIFICATE`/`WINDOWS_CERTIFICATE_PASSWORD` (`.pfx`) or the Azure Trusted Signing `AZURE_*` secrets; none is set for this repository yet, so Windows builds are unsigned. All are optional: a missing one produces unsigned artifacts with a warning, never a failed build.
- **Local packaging test:** `packaging/macos/package.sh` (ad-hoc signed DMG), `packaging/linux/package.sh`.
